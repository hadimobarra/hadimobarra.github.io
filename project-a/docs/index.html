Getting Started


Welcome to Nexus AI documentation. This guide will help you set up and configure your development environment.


Prerequisites


  • Node.js 18+
  • npm or yarn
  • Git

    • Installation


    npx create-nexus-app my-project

    cd my-project

    npm run dev


    Configuration


    Create a .env.local file with your API keys:


    NEXT_PUBLIC_API_URL=https://api.nexusai.dev

    OPENAI_API_KEY=your-key-here
