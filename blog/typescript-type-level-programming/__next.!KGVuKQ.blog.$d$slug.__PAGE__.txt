11:T30ae,<h2 id="types-are-a-programming-language">Types are a programming language</h2>
<p>TypeScript's type system is Turing-complete, which in practice means you can compute types from other types. Once you see it as a small functional language — with <em>functions</em> (generic types), <em>conditionals</em> (conditional types), <em>loops</em> (recursion and mapped types) and <em>string manipulation</em> (template literal types) — advanced library types stop looking like magic.</p>
<h2 id="generic-types-are-functions">Generic types are functions</h2>
<div class="code-block" dir="ltr"><pre tabindex="0"><code class="hljs language-ts"><span class="hljs-keyword">type</span> <span class="hljs-title class_">Box</span>&#x3C;T> = { <span class="hljs-attr">value</span>: T };       <span class="hljs-comment">// a function from T to a type</span>
<span class="hljs-keyword">type</span> <span class="hljs-title class_">StringBox</span> = <span class="hljs-title class_">Box</span>&#x3C;<span class="hljs-built_in">string</span>>;     <span class="hljs-comment">// calling it</span>

<h2 id="conditional-types-are-if-statements">Conditional types are <code>if</code> statements</h2>
<div class="code-block" dir="ltr"><pre tabindex="0"><code class="hljs language-ts"><span class="hljs-keyword">type</span> <span class="hljs-title class_">IsString</span>&#x3C;T> = T <span class="hljs-keyword">extends</span> <span class="hljs-built_in">string</span> ? <span class="hljs-literal">true</span> : <span class="hljs-literal">false</span>;

<h2 id="the-distributive-surprise">The distributive surprise</h2>
<p>When the checked type is a <strong>naked type parameter</strong> and you pass a union, the conditional is applied to each member separately:</p>
<div class="code-block" dir="ltr"><pre tabindex="0"><code class="hljs language-ts"><span class="hljs-keyword">type</span> <span class="hljs-title class_">ToArray</span>&#x3C;T> = T <span class="hljs-keyword">extends</span> <span class="hljs-built_in">unknown</span> ? T[] : <span class="hljs-built_in">never</span>;
<span class="hljs-keyword">type</span> X = <span class="hljs-title class_">ToArray</span>&#x3C;<span class="hljs-built_in">string</span> | <span class="hljs-built_in">number</span>>; <span class="hljs-comment">// string[] | number[]  (not (string | number)[])</span>
</code></pre><span class="code-lang">ts</span><button type="button" class="code-copy" data-copy-code="" aria-label="Copy code"><svg width="14" height="14" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" aria-hidden="true"><rect x="9" y="9" width="13" height="13" rx="2"></rect><path d="M5 15H4a2 2 0 0 1-2-2V4a2 2 0 0 1 2-2h9a2 2 0 0 1 2 2v1"></path></svg></button></div>
<p>That's usually what you want (it's how <code>Exclude</code> and <code>Extract</code> work), but sometimes it isn't. Wrap both sides in a tuple to turn distribution off:</p>
<div class="code-block" dir="ltr"><pre tabindex="0"><code class="hljs language-ts"><span class="hljs-keyword">type</span> <span class="hljs-title class_">ToArrayNonDist</span>&#x3C;T> = [T] <span class="hljs-keyword">extends</span> [<span class="hljs-built_in">unknown</span>] ? T[] : <span class="hljs-built_in">never</span>;
<span class="hljs-keyword">type</span> Y = <span class="hljs-title class_">ToArrayNonDist</span>&#x3C;<span class="hljs-built_in">string</span> | <span class="hljs-built_in">number</span>>; <span class="hljs-comment">// (string | number)[]</span>

<h2 id="keeping-the-compiler-happy">Keeping the compiler happy</h2>

</ul>

<li><strong>Editor performance.</strong> Deep types on hot paths slow down IntelliSense for everyone. Check with <code>tsc --extendedDiagnostics</code> and <code>--generateTrace</code>.</li>
<li><strong>Readability.</strong> Name intermediate types and add a short comment explaining <em>what</em> the type computes. Future you will need it.</li>
</ul>
<h2 id="conclusion">Conclusion</h2>
<p>Conditional types are branching, <code>infer</code> is pattern matching, mapped types are loops, and template literals are string processing. Use them at the <strong>edges</strong> of your system — routers, API clients, form libraries, config loaders — where a strong type stops whole categories of bugs, and keep everyday application types simple.</p>
