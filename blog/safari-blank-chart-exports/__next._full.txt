<ol>
<li>Clone the DOM node and copy its computed styles inline.</li>
<li>Put the clone into an SVG, inside a <code>&#x3C;foreignObject></code>. That element exists to embed HTML in SVG.</li>
<li>Load the SVG as an image and draw it to a canvas.</li>
<li>Read the canvas with <code>toDataURL()</code>.</li>
</ol>
<p>Step 2 is where WebKit stops. It applies a stricter security model to <a href="https://developer.mozilla.org/en-US/docs/Web/SVG/Reference/Element/foreignObject"><code>foreignObject</code></a> content and refuses to paint it, so the canvas in step 3 stays empty. Nothing throws. <code>toDataURL()</code> happily encodes an empty canvas.</p>
<p>The library's own README lists Safari as unsupported for this reason. That changes the shape of the problem: there is no missing option to find. No setting in this library can work.</p>
<h2 id="choosing-a-fix-you-can-defend">Choosing a fix you can defend</h2>
<p>There were three candidates.</p>

<h2 id="problem-two-content-that-isnt-visible-yet">Problem two: content that isn't visible yet</h2>
<p>Superset tables are virtualized: only the rows on screen exist in the DOM. The existing path switches ag-grid to its print layout before capturing, then restores it. My first version returned early and skipped all of that, so long tables would have been cut off. The final version keeps the whole lifecycle and replaces only the rasterizing step.</p>
<p>A related bug was more subtle. I measured the element, then expanded its clipped content inside the clone. The canvas was therefore sized for the collapsed version. <code>html2canvas</code> reads its dimensions after the <code>onclone</code> callback, so the fix is to widen them there:</p>

<p><code>Math.max</code> keeps the on-screen size as a floor, so a clone that can't be measured never makes the result smaller.</p>
<h2 id="problem-three-webgl-canvases-read-back-empty">Problem three: WebGL canvases read back empty</h2>
<p>A cloned <code>&#x3C;canvas></code> is blank, because cloning copies the element and not its pixels. For 2D canvases you copy the pixels with <code>drawImage</code>. WebGL adds a catch: after a frame is presented, the browser may clear the drawing buffer. Read it later and you get nothing.</p>
<p>The fix is a context option, <a href="https://developer.mozilla.org/en-US/docs/Web/API/HTMLCanvasElement/getContext"><code>preserveDrawingBuffer</code></a>. It has a cost, so it's set only on Safari.</p>
<p>deck.gl needed one more step. It drew its layers into a second canvas laid over the map, with its own context and its own unpreserved buffer. A chart would have exported the map without the data. In interleaved mode deck.gl renders into the base map's context instead, so one preserved buffer holds everything.</p>
<h2 id="problem-four-images-you-arent-allowed-to-read">Problem four: images you aren't allowed to read</h2>
<p>An image from another origin without CORS headers <em>taints</em> a canvas. A <a href="https://developer.mozilla.org/en-US/docs/Web/HTML/How_to/CORS_enabled_image">tainted canvas</a> refuses <code>toDataURL()</code>, so one logo could break the entire export. A review bot flagged that such images would be missing. I kept <code>useCORS: true</code> and tainting off: the inaccessible image is left out, and everything else exports. That is also what the old path did.</p>
<h2 id="what-i-got-wrong">What I got wrong</h2>
<p>I don't have access to a Mac, and jsdom can't render WebGL. My tests prove that <code>interleaved</code> reaches the component on Safari. They can't prove that a heatmap appears.</p>
<p>A reviewer tested on real Safari and found that interleaved mode exposed a version mismatch in the lockfile: the deck.gl map adapter called a method that the installed deck.gl core didn't have. Superset's main branch has since moved both packages to the same version.</p>
<blockquote>
<p>A test that checks configuration tells you the switch was flipped. It doesn't tell you the light came on.</p>
</blockquote>
<h2 id="what-to-take-from-it">What to take from it</h2>
<ul>
<li><strong>Silent failures deserve suspicion.</strong> An empty canvas is valid data to every later step.</li>
<li><strong>Read the library's support table early.</strong> It rules out every option that could never have worked.</li>
<li><strong>Contain the change.</strong> Browsers that already worked kept their exact path.</li>
<li><strong>Ask who can run it.</strong> If you can't test the engine you're fixing, arrange that before you open the PR.</li>
</ul>
