<h2 id="producing-streams">Producing streams</h2>
<p>You can create streams from any source, including an async generator:</p>
<div class="code-block" dir="ltr"><pre tabindex="0"><code class="hljs language-js"><span class="hljs-keyword">function</span> <span class="hljs-title function_">fromAsyncIterable</span>(<span class="hljs-params">iterable</span>) {

<h2 id="conclusion">Conclusion</h2>
<p>When you model data as a sequence over time, users see the first result sooner, memory stays flat regardless of input size, and cancellation works naturally. Generators make sequences easy to write, async iteration makes them easy to consume, and Web Streams connect them to the network on every modern JavaScript runtime.</p>
